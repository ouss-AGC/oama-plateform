À Propos de la Plateforme

Une Solution Innovante pour l'Évaluation Académique

OAMA-Plateform est une application web développée par le Lt Col Oussama Atoui pour moderniser l'évaluation des élèves officiers à l'Académie Militaire de Fondouk Jédid.

La plateforme permet de créer et gérer des sessions de quiz en temps réel, avec un système de PIN pour contrôler l'accès, un tableau de bord administrateur pour suivre les résultats, et la génération automatique de certificats.

Actuellement déployée en ligne sur Render.com, la plateforme nécessite des améliorations pour répondre aux exigences de sécurité et de déploiement local de l'institution.

Fonctionnement

Comment Fonctionne la Plateforme

1

Génération du PIN

L'administrateur génère un code PIN à 6 chiffres pour créer une nouvelle session de quiz.

2

Inscription Étudiants

Les étudiants entrent le PIN et renseignent leurs informations (grade, nom, matricule, classe).

3

Lancement du Quiz

L'administrateur démarre le quiz. Tous les étudiants en salle d'attente sont redirigés automatiquement.

4

Résultats & Analyse

Les résultats sont collectés en temps réel avec statistiques, export CSV/PDF et certificats.

Architecture Technique

Stack Technologique Actuel

Comprendre l'architecture existante pour mieux contribuer aux améliorations.

Frontend - React + TypeScript

Interface utilisateur moderne avec Vite, TailwindCSS, et composants réutilisables pour une expérience fluide.

Backend - Express.js

Serveur Node.js avec API REST pour la gestion des sessions, validation PIN, et soumission des résultats.

Stockage - In-Memory

Données stockées en mémoire (non persistantes). Point d'amélioration majeur pour la production.

Génération PDF - jsPDF

Création de certificats et rapports PDF côté client avec jsPDF et autoTable.

Visualisation - Recharts

Graphiques interactifs pour l'analyse des performances et statistiques de classe.

Déploiement - Render.com

Hébergement cloud actuel. Objectif: migration vers déploiement local sécurisé.

Sécurité

Sécurisation Avancée de la Plateforme OAMA

Objectif

Concevoir et implémenter un système de sécurité complet pour la plateforme OAMA, garantissant la confidentialité des données, l'intégrité des évaluations et la conformité aux exigences de sécurité militaire.

Démarche / Phases

  • Phase 1: Audit de sécurité de l'application existante et identification des vulnérabilités
  • Phase 2: Conception de l'architecture de sécurité (authentification, autorisation, chiffrement)
  • Phase 3: Implémentation de l'authentification multi-facteurs (MFA) pour les administrateurs
  • Phase 4: Mise en place du chiffrement des données sensibles (AES-256, TLS 1.3)
  • Phase 5: Développement du système d'audit logging et détection d'intrusion
  • Phase 6: Tests de pénétration et validation de la sécurité

Type du Travail

Étude + Développement/Réalisation pratique

Résultats Attendus

  • Rapport d'audit de sécurité complet
  • Module d'authentification MFA fonctionnel
  • Système de chiffrement des données implémenté
  • Dashboard de monitoring de sécurité
  • Documentation des procédures de sécurité

Besoins (Matériel/Logiciels)

  • Node.js, Express.js, React
  • Bibliothèques: bcrypt, jsonwebtoken, helmet, crypto
  • Outils de test: OWASP ZAP, Burp Suite
  • Serveur de test local

Prérequis

  • Connaissances en développement web (JavaScript, Node.js)
  • Notions de cryptographie et sécurité informatique
  • Familiarité avec les protocoles d'authentification (OAuth, JWT)

Infrastructure

Déploiement Local et Architecture On-Premise

Objectif

Concevoir et mettre en œuvre une solution de déploiement local permettant à la plateforme OAMA de fonctionner entièrement sur le réseau interne de l'académie, sans dépendance à Internet, tout en garantissant performance et fiabilité.

Démarche / Phases

  • Phase 1: Analyse des besoins infrastructure et contraintes réseau de l'académie
  • Phase 2: Conception de l'architecture serveur locale (Docker, reverse proxy)
  • Phase 3: Configuration du serveur et installation des dépendances
  • Phase 4: Adaptation de l'application pour fonctionnement offline
  • Phase 5: Mise en place du système de backup et restauration
  • Phase 6: Documentation et formation des administrateurs

Type du Travail

Conception/Modélisation + Développement/Réalisation pratique

Résultats Attendus

  • Architecture de déploiement documentée
  • Scripts d'installation automatisés (Docker Compose)
  • Plateforme fonctionnelle sur réseau local
  • Système de backup automatique
  • Guide d'administration et maintenance

Besoins (Matériel/Logiciels)

  • Serveur Linux (Ubuntu Server 22.04 LTS)
  • Docker et Docker Compose
  • Nginx (reverse proxy)
  • Routeur WiFi pour tests en environnement isolé

Prérequis

  • Administration système Linux
  • Connaissances Docker et containerisation
  • Notions de réseaux informatiques

Data

Base de Données et Tableau de Bord Analytique Avancé

Objectif

Remplacer le stockage en mémoire par une base de données persistante robuste et développer un tableau de bord analytique avancé permettant le suivi longitudinal des performances des étudiants et des statistiques détaillées.

Démarche / Phases

  • Phase 1: Conception du schéma de base de données (modèle relationnel)
  • Phase 2: Migration vers PostgreSQL/SQLite avec ORM (Prisma/Sequelize)
  • Phase 3: Implémentation du système de backup automatique
  • Phase 4: Développement du dashboard analytique (graphiques, KPIs)
  • Phase 5: Création des rapports exportables (PDF, Excel)
  • Phase 6: Tests de performance et optimisation des requêtes

Type du Travail

Conception/Modélisation + Développement/Réalisation pratique

Résultats Attendus

  • Base de données PostgreSQL/SQLite opérationnelle
  • Système de backup et restauration automatique
  • Dashboard analytique avec visualisations interactives
  • Suivi historique des performances par étudiant
  • Exports automatisés (rapports PDF/Excel)

Besoins (Matériel/Logiciels)

  • PostgreSQL ou SQLite
  • Prisma ou Sequelize (ORM)
  • Chart.js, Recharts ou D3.js
  • jsPDF, ExcelJS pour exports

Prérequis

  • Bases de données relationnelles (SQL)
  • Développement backend Node.js
  • Visualisation de données

Extension

Extension Multi-Disciplines et Gestion de Contenu

Objectif

Développer un système de gestion de contenu (CMS) permettant aux instructeurs de créer, modifier et organiser les quiz de manière autonome, avec support pour de nouveaux types de questions et une architecture multi-disciplines extensible.

Démarche / Phases

  • Phase 1: Analyse des besoins des instructeurs et types de questions souhaités
  • Phase 2: Conception de l'interface CMS (création/édition de quiz)
  • Phase 3: Développement de l'éditeur de questions (QCM, vrai/faux, appariement, etc.)
  • Phase 4: Implémentation du système de gestion des disciplines
  • Phase 5: Création du système d'import/export de quiz (JSON, CSV)
  • Phase 6: Tests utilisateurs et documentation

Type du Travail

Conception/Modélisation + Développement/Réalisation pratique

Résultats Attendus

  • Interface CMS complète pour gestion des quiz
  • Support de nouveaux types de questions (drag-drop, appariement, texte à trous)
  • Système de catégorisation par discipline/module
  • Import/Export de banques de questions
  • Guide utilisateur pour les instructeurs

Besoins (Matériel/Logiciels)

  • React, TypeScript
  • Éditeur WYSIWYG (TipTap, Slate)
  • Drag-and-drop library (react-beautiful-dnd)

Prérequis

  • Développement frontend React avancé
  • Design d'interfaces utilisateur
